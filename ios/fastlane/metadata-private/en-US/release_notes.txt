What's new in this beta

- Agent Management (Pro): install, repair, and update coding agents and their ACP adapters on a host from your phone. See installed and latest versions, or update supported installations together.
- A dot on the terminal menu now shows when agent updates are available. Turn it off under Settings > Agent update indicators.
- Native agent windows reconnect more reliably after the phone sleeps or a MonkeyMux bridge goes stale.
- Retrying a prompt after an error no longer shows the old error.
- On Windows hosts, agents launch through PowerShell and stray color codes no longer spill into the terminal.
- Gemini CLI support has been removed. Saved presets for it are ignored instead of failing.
- Layout fixes for the home screen and for MonkeyMux sheets under the keyboard.

Please report rough edges through the support link.
