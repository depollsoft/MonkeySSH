Test the latest MonkeySSH agent workflows on iPhone or iPad. MonkeySSH beta puts native agent conversations, a full SSH terminal, MonkeyMux or tmux windows, and SFTP in one remote workspace.

Choose the right view for each task:

- Chat with supported agents in native windows with streaming replies, tool progress, plans, diffs, permission prompts, images, audio, attachments, slash commands, and session history. Sign in, answer agent forms, view tool output, and choose MCP servers and extra working directories when supported. Model and mode controls depend on the agent. Search and export chats, catch up with a summary of what changed while you were away, keep unsent drafts after the app closes, and take over a chat from another device in one tap. Add your own ACP agents.
- Get notified when an agent finishes a turn or needs you, even while the app is closed. Choose notifications per host. Connections shows what is waiting on you first.
- Switch to the full terminal whenever you need direct CLI control, xterm-256color, inline images, gestures, modifier keys, function keys, macros, or IME-friendly typing. Swipe up on toolbar keys for shortcuts and symbols. Find text in the scrollback and export it.
- Keep agent and shell work running in persistent MonkeyMux windows. Reconnect, switch windows, and share the same session with your desktop.
- Launch Claude Code, Copilot CLI, Codex, OpenCode, Antigravity, Cursor Agent, Pi, Hermes, OpenClaw, Grok Build, and Muse Code, find recent project-scoped sessions, and save launch presets per host. A preset can start the agent in a new git worktree with an initial prompt.
- Review a host's working tree changes and diffs, and ask the agent about any hunk.
- Manage agent CLIs and ACP adapters on a host with Agent Management. Check versions, install or repair supported packages, and update supported installations together. See account usage, remaining allowances, and reset times when available. A dot on the terminal menu flags available updates.
- Browse, sort, filter, upload, download, create, and edit remote files over SFTP, act on many files at once, and extract zip and tar archives on the host.
- Generate or import Ed25519 and RSA keys, install a key on a host and confirm key-only login, and share a public key as a QR code. Import hosts from an ssh_config, verify host keys, use jump hosts, forward your SSH agent, and cancel slow connection attempts.
- Forward remote ports and SOCKS proxies, manage live tunnels, and browse through them in the in-app browser.
- Save snippets that type text and press keys, macros, home-screen shortcuts, and per-host startup settings for repeat work. Open hosts, windows, and chats from monkeyssh:// and ssh:// links, and use keyboard shortcuts with a hardware keyboard.

Your hosts, keys, snippets, and settings stay on your device. PIN and biometric lock are available, and MonkeySSH does not require cloud sync. Optional analytics and crash reports are off by default and exclude commands, terminal output, paths, hostnames, usernames, clipboard contents, and credentials. Push notifications are also off by default, and their details are encrypted so only your device can read them.

SSH, terminal, SFTP, one connected native chat, and the choice between native and terminal agent windows are free. MonkeySSH Pro adds parallel native chats with instant switching and session forks, agent launch presets and recent-session discovery, Agent Management and supported-agent usage rings in MonkeyMux, SSH agent forwarding, auto-connect automation, encrypted transfers and migration packages, and host-specific themes.

This beta listing receives preview and internal testing builds before the public MonkeySSH app.
