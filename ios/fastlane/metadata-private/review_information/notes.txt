MonkeySSH Pro is available from Settings > MonkeySSH Pro and from prompts for Pro features.

The purchase screen displays App Store prices, monthly or annual renewal terms, and working links to:
- Terms of Use: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
- Privacy Policy: https://github.com/depollsoft/MonkeySSH/blob/main/docs/privacy-policy.md

The private beta app requests only these private product IDs:
- monkeyssh_pro_monthly
- monkeyssh_pro_annual
- monkeyssh_pro_lifetime (non-consumable, redeemed only through App Store offer codes; it is not shown on the purchase screen and surfaces through the purchase and restore flow)

Reviewers can explore the main app without an account, SSH server, or external agent credentials:

1. Open MonkeySSH.
2. Open Settings.
3. Scroll to About and tap App Review Demo.
4. Tap Load demo data.
5. Return to Hosts and open either App Review Demo host.

The offline demo uses an in-app local transport. It includes hosts, keys, snippets, SFTP files, port-forward rules, host themes, and local MonkeyMux windows. Reviewers can switch windows and create windows for Copilot CLI, Claude Code, OpenCode, Codex, Antigravity, SFTP, and shell workflows.

Native agent windows normally connect through SSH and MonkeyMux to a supported coding agent installed and authenticated on the user's own server. The offline review demo does not contact those third-party agent services, so its panes use fixed sample content. The store screenshots and App Preview were captured separately from a live local SSH and MonkeyMux workspace with live Copilot CLI and Claude Code panes. Native-chat conversations use authenticated Copilot.

Agent Management (Pro) is opened from the terminal menu on a connected host. It runs npm, pipx, Homebrew, or the agent's own update command on the user's server over SSH to install, repair, or update coding agents. The offline demo does not install or update anything.

The offline demo requires no username or password.
