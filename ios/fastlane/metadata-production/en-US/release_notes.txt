What's new

- Kitty inline images now work inside tmux sessions, using tmux 3.8+ native graphics or passthrough on tmux 3.3 and newer.
- Redesigned SFTP filtering and view options: toggle the filter bar from the search button, highlight matching text in filenames, tap the sort pill to change sort order or hidden files live, and long-press it to flip sort direction.
- Swipe left, right, or down to dismiss in-app banners and foreground push notifications.
- Faster SSH connections and lower data use: OpenSSH compression cuts terminal and agent traffic, keystroke echo no longer waits on a flush timer, and terminal rendering uses fewer draw calls.

What's fixed

- Restored Copilot CLI inline image display inside MonkeyMux windows.
- Restored Antigravity account usage in Agent Management on current agy builds.
- Tapping terminal links and file paths now opens them even when your finger rests longer than 100 ms, and explicit terminal file links open the exact path in SFTP.
- Touch scrolling in Copilot CLI now moves one row per step instead of jumping ahead, and Hermes touch scrolling no longer accelerates past your finger.
- Native agent windows whose remote bridge already exited can now be closed instead of staying stuck open.
- Agent request errors now show the agent's underlying reason when it returns a generic internal error.
