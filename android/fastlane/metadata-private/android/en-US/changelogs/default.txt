What's new in this beta

- Agent Management (Pro): install, repair, and update coding agents and their ACP adapters on a host, with version checks and batch updates for supported installs.
- A dot on the terminal menu shows when agent updates are available.
- Native agent windows reconnect more reliably after sleep or a stale MonkeyMux bridge.
- Windows hosts: agents launch through PowerShell and stray color codes are gone.
- Gemini CLI support removed; saved presets for it are ignored.
